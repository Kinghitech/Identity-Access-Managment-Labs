# Identity & Access Management Labs

Hands-on Identity & Access Management (IAM) labs focused on Microsoft Entra ID, authentication, authorization, identity governance, privileged access, provisioning, lifecycle management, and IAM automation.

The purpose of this repository is to demonstrate practical IAM skills through documented lab environments and real-world identity administration scenarios.
