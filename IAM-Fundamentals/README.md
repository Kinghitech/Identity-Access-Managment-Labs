# IAM Fundamentals

## Overview

This lab introduces the fundamental concepts of Identity and Access Management (IAM) through the IAAA model:

* Identification
* Authentication
* Authorization
* Accountability

The lab also covers identity management, access control models, Single Sign-On (SSO), authentication attacks, logging, and practical IAM scenarios.
